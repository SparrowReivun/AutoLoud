# AutoLoud：我们要解决什么，以及程序是怎么想的

2026-10-25

## 一、痛点

**不同媒体之间的音量差距太大。** 响度最高的通常是制作精良的音乐和游戏；制作精良的电影和视频出于审美考虑，响度往往比前两者低很多；非专业制作的短视频、UP 主视频更是参差不齐。结果就是上网时每打开一个新东西，都得先小心翼翼地把音量调一遍——开着音乐切到视频听不见，看完视频切回音乐被轰一下。

**很多软件自己的音量逻辑做得不好，连热门游戏也不例外。** 以《绝区零》为例：为了一边打游戏一边在外面看攻略视频或放点背景音乐，我把游戏主音量调到一半；结果每到剧情 CV 或过场视频，声音就突然变得特别大。实测下来，游戏的主音量旋钮根本管不到游戏内的视频音量。这类问题用户在软件里是没法自己解决的。

**突然的大音量不只是烦，还伤听力。** 戴着耳机时一个意料之外的铃声、广告或过场，瞬间可能比正常听音大 20 dB 以上。

## 二、我们怎么解决

做一个系统级的小工具：你校准一次"我觉得多响合适"，之后它盯着电脑的全部声音输出，把每个应用的音量自动调到让你听起来始终舒服。既管全局，也能单独管每一个应用。

这套东西分两层。第一层是现在已经做好的**自动响度**：保证听音舒适、各来源之间相对均衡，并挡住极端的大音量。第二层是将来的**智能混音**：结合自动混音技术和"用户现在正在用哪个程序"的识别，让你专注于眼前的场景，同时又能听清背景里正在播放的信息——比如打游戏时游戏音效清楚、背景的攻略视频听得见但不抢戏。

## 三、程序里的每个判断，用大白话说

**先问清楚你的耳朵，而不是用一个固定标准。** 校准分两步：先放一段刺耳的滴声，你把推子推到"吵但还能忍"，这是上限 A；再放音乐（内置曲目，或者你用任何软件放自己的歌），推到舒服，这是目标 B。每副耳机 / 音箱各存一套，因为同样的数字音量在不同设备上响度完全不同。

**我们测的是"听起来多响"，不是"信号多大"。** 用的是广播和流媒体行业统一的响度标准（BS.1770，单位 LUFS），它会模拟人耳对不同频率的敏感程度，并自动忽略静音和安静段落。所以一首前奏很轻的歌不会被误判成"整体很轻"然后被推得过响。

**不改声音本身，只调音量旋钮。** 程序从 Windows 拿一份正在播放的声音副本来测量，然后去拧每个应用的音量和主音量。这样不用装驱动，不引入延迟，声音路径一点没变；代价是做不了那种毫秒级的"削峰"，所以对付突发大音量要靠下面几条规则。

**安静之后第一声，宁可轻，不能炸。** 没声音的时候，程序就预先把音量压到一个保守位置：哪怕突然来一个非常响的铃声，听到的也不会超过上限 A。声音出现后的 2 秒内，一边测量它实际多响，一边平滑地把它升到目标 B。

**正在听的过程中，不要频繁动。** 音乐和电影本身有强弱起伏，这是作品的一部分，不能抹平。所以稳定播放时程序以 30 秒为一段来看"这一段整体多响"，只在段落之间做一次调整，而且每次都是 2 秒内渐变，不会跳。第一段只有 12 秒，因为刚开始那 2 秒的估计还比较粗，需要早一点修正一次。

**但真的太响了，立刻压。** 如果某一瞬间比目标响了 8 dB 以上（典型情况：视频中间插进来一条广告、游戏突然切到过场），不等这 30 秒结束，0.3 秒内直接压下去。8 dB 这个门槛是为了不误伤音乐里正常的强弱对比。

**已经在听的时候又来一个新声音，不重新从头保护。** 比如音乐放着，又打开一个视频。这时不会把音量先压到 A 再升回来——那样听感会断一下——而是交给下一次段落调整自然处理。只有从完全安静到有声音，才走"先保守再升"的流程。

**每个应用一条推子，而且它们是"相对"的。** 混音台页面里每个发声的应用都有一条 ±40 dB 的推子，不管自动响度开没开都有效。Windows 不允许把单个应用放大到超过 100%，所以当你把某个应用推到 0 dB 以上时，程序是抬高主音量、同时把别的应用压低相同的量来实现的。推子的设置按程序名记住，下次再打开同一个程序自动恢复；程序名不好认（比如 Apple Music 显示为 AMP）可以自己改备注。

**自动响度可以按应用单独关掉。** 每个应用旁边有一个"自动"开关：勾上，总线的自动增益作用于它；不勾，它就只按自己的推子固定。这样可以让通话保持固定音量，只让音乐和视频参与自动均衡。因为程序听到的是整个混音，分不清每个应用各自多响，所以会用每个应用的电平表估算"参与自动的那部分占多少"，把关掉自动的应用从测量里扣掉，避免一个固定音量的通话把其它应用一路压到底。

**关掉软件，一切复原。** 退出时所有应用音量和主音量都回到原样，不留痕迹。

## 四、现在的边界

蓝牙耳机的音量是在耳机端生效的，程序听不到主音量的变化；校准时会自动探测并按这种情况处理，但探测还不够稳。按"哪首歌 / 哪个视频"来切分响度目前做不到，只能到"哪个程序"这一级，这是下一步要接 Windows 媒体会话接口来解决的。智能混音还没开始做，现有的每应用推子和"自动"开关就是它的地基。
