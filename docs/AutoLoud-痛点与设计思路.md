# AutoLoud：我们要解决什么，以及程序是怎么想的

2026-10-25

## 一、痛点

**不同媒体之间的音量差距太大。** 响度最高的通常是制作精良的音乐和游戏；制作精良的电影和视频出于审美考虑，响度往往比前两者低很多；非专业制作的短视频、UP 主视频更是参差不齐。结果就是上网时每打开一个新东西，都得先小心翼翼地把音量调一遍——开着音乐切到视频听不见，看完视频切回音乐被轰一下。

**很多软件自己的音量逻辑做得不好，连热门游戏也不例外。** 以《绝区零》为例：为了一边打游戏一边在外面看攻略视频或放点背景音乐，我把游戏主音量调到一半；结果每到剧情 CV 或过场视频，声音就突然变得特别大。实测下来，游戏的主音量旋钮根本管不到游戏内的视频音量。这类问题用户在软件里是没法自己解决的。

**突然的大音量不只是烦，还伤听力。** 戴着耳机时一个意料之外的铃声、广告或过场，瞬间可能比正常听音大 20 dB 以上。

## 二、我们怎么解决

做一个系统级的小工具：你校准一次"我觉得多响合适"，之后它盯着电脑的全部声音输出，把每个应用的音量自动调到让你听起来始终舒服。既管全局，也能单独管每一个应用。

这套东西分两层。第一层是现在已经做好的**自动响度**：保证听音舒适、各来源之间相对均衡，并挡住极端的大音量。第二层是将来的**智能混音**：结合自动混音技术和"用户现在正在用哪个程序"的识别，让你专注于眼前的场景，同时又能听清背景里正在播放的信息——比如打游戏时游戏音效清楚、背景的攻略视频听得见但不抢戏。

## 三、程序里的每个判断，用大白话说

**先问清楚你的耳朵，而不是用一个固定标准。** 校准只有一步：把外部设备和 Windows 主音量放到 80% 左右，放一首你喜欢的音乐（内置曲目，或者你用任何软件放自己的歌），把推子从 0 慢慢拉高到舒服，这就是目标 B。（早期版本还用刺耳的滴声测一个"上限 A"，已经取消：下限直接取 B − 5 dB。）每副耳机 / 音箱各存一套，因为同样的数字音量在不同设备上响度完全不同。

**我们测的是"听起来多响"，不是"信号多大"。** 用的是广播和流媒体行业统一的响度标准（BS.1770，单位 LUFS），它会模拟人耳对不同频率的敏感程度，并自动忽略静音和安静段落。所以一首前奏很轻的歌不会被误判成"整体很轻"然后被推得过响。

**不改声音本身，只调音量旋钮。** 程序从 Windows 拿一份正在播放的声音副本来测量，然后去拧每个应用的音量和主音量。这样不用装驱动，不引入延迟，声音路径一点没变；代价是做不了那种毫秒级的"削峰"，所以对付突发大音量要靠下面几条规则。

**安静之后第一声，宁可轻，不能炸。** 没声音的时候，程序就预先把音量压到一个保守位置：哪怕突然来一个非常响的铃声，听到的也不会超过 B − 5 dB。声音出现后的一个步长（默认 5 秒）内，一边测量它实际多响，一边平滑地把它升到目标 B 附近。

**什么时候算"新作品"，重新来一遍。** 能拿到播放器的切歌、切视频信息（系统媒体会话里的标题 / 作者 / 专辑），就跟着它判断；暂停、继续、拖进度、换封面都不算。拿不到的话，某个应用连续 15 秒接近无声，下一次出声就当作新作品。新作品开始时先沿用这个应用上次的音量；第一次使用的应用从偏轻一点的位置（当前再低 3 dB）起步。

**刚开始，怎么调到舒服：听一段，拧一点，再听一段。** 先听满 5 秒再决定。偏轻：最多加 1 dB，渐变时间和一段听的时长一样（默认 5 秒）。偏响：最多减 0.8 dB，同样的渐变时间；只有新作品开始后的第一次偏响例外，一步直接降到位。离 B 不到 2 dB：一步直接调到 B，不再一点点蹭。已经在 B 上下 2 dB 之内：停止调整。每次调完，再听满 5 秒才决定下一次。不是一口气拉到目标，往上小心，往下快一些。

**舒服以后，就别追着声音调。** 轻声对白、安静间奏、结尾渐弱，让它自然变轻；高潮来了，可以变响。只有连续两段都整体超过 B + 6 dB（偶尔一段响不算），或者连续三段都低于 B − 20 dB（真的一直太轻了），才重新开始调整，方法还是上面那套，直到回到 B 附近。

**突然特别响，怎么办。** 这一条随时有效，不等 5 秒。瞬时响度超过 B + 13 dB（阈值在首页调，范围 −5 到 +25 dB），就在 0.15 秒内急速压到 B + 5 dB——按当下真正在响的增益算，等表跟上后再补一次——不直接压回 B。弹窗停留 10 秒，里面直接放着舒适响度 B 的滑块。软件是听到以后再降，所以第一下已经出来的声音没办法收回。

**压低以后，别马上弹回来。** 进入保护时立即压低并弹出提示：识别到巨大音量，已自动进入响度过高保护；如果觉得保护过于频繁，请调大阈值。提示上有推子可以直接改阈值。从弹窗出现开始计时，5 秒内没人操作就关闭弹窗，从当前音量按"听一段、拧一点"重新调整。有一条例外：如果大音量已经过去、现在明显偏轻，那么回到"被压之前的音量"这一段路可以走得快一些（每步 2 dB），否则一条广告之后电影要小声好几分钟。

**你自己调音量时，听你的。** 你手动动了某个应用的推子，自动增益在这个应用的当前作品结束之前不再碰它，软件不会马上又拧回去。你动了 Windows 主音量，新的总音量就成为新的舒适值 B，程序以它为新基准继续工作。

**每个应用一条推子，而且它们是"相对"的。** 混音台页面里每个发声的应用都有一条推子（最低静音，最高 +15 dB），不管自动响度开没开都有效。Windows 不允许把单个应用放大到超过 100%，所以当你把某个应用推到 0 dB 以上时，程序是抬高主音量、同时把别的应用压低相同的量来实现的。推子的设置按程序名记住，下次再打开同一个程序自动恢复；程序名不好认（比如 Apple Music 显示为 AMP）可以自己改备注。

**自动响度可以按应用单独关掉。** 每个应用旁边有一个"自动"开关：勾上，总线的自动增益作用于它；不勾，它就只按自己的推子固定。这样可以让通话保持固定音量，只让音乐和视频参与自动均衡。因为程序听到的是整个混音，分不清每个应用各自多响，所以会用每个应用的电平表估算"参与自动的那部分占多少"，把关掉自动的应用从测量里扣掉，避免一个固定音量的通话把其它应用一路压到底。

**关掉软件，一切复原。** 退出时所有应用音量和主音量都回到原样，不留痕迹。

## 四、现在的边界

蓝牙耳机的音量是在耳机端生效的，程序听不到主音量的变化；校准时会自动探测并按这种情况处理，但探测还不够稳。按"哪首歌 / 哪个视频"来切分响度目前做不到，只能到"哪个程序"这一级，这是下一步要接 Windows 媒体会话接口来解决的。智能混音还没开始做，现有的每应用推子和"自动"开关就是它的地基。
