# AutoLoud

**校准一次，之后切换任何视频 / 应用都不用再碰音量。**

AutoLoud 把 Windows 上所有声音自动拉平到你自己校准出来的舒适响度。它不装驱动、不改音频流，只是实时测量系统输出有多响（ITU-R BS.1770 LUFS），再悄悄调整每个应用的音量把结果对准目标。

> English: see [README.en.md](README.en.md). 界面语言首次启动时跟随系统语言，可在「设置」里切换。

## 下载与安装

1. 到 [Releases](../../releases) 下载最新的 `AutoLoud.exe`（单文件，约 100 MB，无需安装 Python）。
2. 双击运行。首次启动 Windows SmartScreen 可能提示「Windows 已保护你的电脑」——点「更多信息 → 仍要运行」。exe 未做代码签名，这是正常现象。
3. 程序会自动打开校准向导，两分钟完成。之后它会缩到托盘里安静工作。

## 它解决什么问题

不同视频、应用的音量差异很大：一个视频开着正好，切到下一个要么轰耳朵要么听不见；通话里突然弹出的提示音吓一跳。AutoLoud 的做法：

- **两个参考值**：P（human preference loudness，你校准 / 滑块设定的舒适响度）和 T（target loudness，规则真正瞄准的目标）。普通模式下 T = P；强力1 模式下 T 由学习得到，在 [P − X, P] 内随应用自身响度滑动。下面所有"T ± 多少"在普通模式下就是"P ± 多少"。
- **起始保护**：从完全安静到有声音出现时，先按「T − 10 dB」播放，用一个步长（默认 2 秒）平滑升到 T；这期间只压不抬，安静的片头不会被猛推。突然出现的大音量铃声不会炸耳。
- **听一段、拧一点**：之后每听满 2 秒决定一次：偏轻最多加 1.3 dB；偏响最多减 2 dB，新作品的第一次偏响则一步到位；离 T 不到 3 dB 时一步直接到位；每步的渐变时间 = 一个步长；比 T 高不到 2 dB、或低不到 3 dB 就算舒适，停下。
- **舒服以后不追着调**：轻声对白、间奏、渐弱都让它自然变轻；只有一段超过 T + 4.5 dB、或连续 3 段都低于 T − 16 dB，才重新开始调（强力1 预设：连续 2 段超过 T + 5、或连续 4 段低于 T − 6）。
- **新作品接着上次**：切歌 / 切视频（系统媒体信息，或 15 秒静音后再出声）时，直接接上这个应用上次的音量，再按上面的方法微调；没见过的应用才走起始保护。（按一次只有一个应用在响来设计。）
- **突然特别响**：瞬时响度超过 T + 14 dB（首页可调）就在 0.05 秒内（可调）压到 T + 2 dB，稳住后自动回到正常规则继续微调。没有弹窗。
- **工具类应用自动排除**：活动但几乎不出声的会话（输入法按键音、通知助手）会被标为「工具类应用」，不参与响度控制也不干扰判断。
- **模式与按应用的预设**：首页选一套参数预设作为当前「模式」（预设在设置页新建）；混音台里每个应用可以选它独自发声时总线改用哪套预设（默认跟随首页）。预设里有两个"强力"开关：「强力：保护触发拉推子」= 每次保护触发把该应用推子拉低超出 T − 5 dB 的量且不回弹（内置预设「强力」）；「目标方式 = 跟随源响度」= 目标 T 不再固定为 P，而是随应用自身响度在 P−X 和 P 之间滑动（内置预设「强力1」，X 默认 5 LU）。
- **强力1 的目标公式**：程序只在恰好一个应用发声时能回推它的源响度 L_src（去掉全部增益）。每个应用慢慢学两个平台——它独自发声时源响度的第 20 / 80 百分位 C_low / C_high（半衰期约 20 分钟发声时间，混音台里能看到、可「重学」）。每个听音块结束时取 u = clip((L_src − C_low)/(C_high − C_low), 0, 1)，T = (P − X) + X·u：应用在它的安静平台上时目标是 P−X，在响亮平台上时目标是 P，再响也只能拿到 P。平台没学够（不足 30 s）或两平台相距不到 1 LU 时 u = 1，T = P；多个应用同时响时 T 保持上一次的值，持续 60 s 测不到就退回 P。应用内音量调小导致源响度整体跌到低平台以下 6 LU 以上两分钟，平台自动按这两分钟重建。
- **应用混音台**：每个发声的应用一条推子（最低静音、最高 +15 dB），叠加在总线之上；推子高于 0 dB 时通过抬高主音量、压低其它应用来实现。
- **音量键调 P**：键盘的音量键 / 外接音量旋钮默认改为调节舒适响度 P（每按一下 1 dB），不再动 Windows 主音量；可在设置里关闭。
- **一切恢复**：退出时，所有应用音量和主音量回到原样。

## 校准

只有一步：先把外部设备（耳机放大器 / 音箱 / 蓝牙耳机）和 Windows 主音量都放到 80% 左右，然后播放一首你喜欢的音乐——内置曲目，或先在任意应用（Spotify、浏览器…）播放再在向导里选中它——把推子从 0 慢慢拉高，停在你觉得舒适的听音音量。这就是「舒适值 P」。

每个输出设备（耳机 / 音箱 / 蓝牙）各自保存一套校准。校准之后不要再动外部设备和主音量——AutoLoud 以它们为基准；P 随时可以在总览页的滑块上微调。

## 从源码运行 / 打包

需要 Python 3.10+。在 PowerShell 里：

```
.\dev.bat                # 建虚拟环境、装依赖、从源码运行
.\build.bat              # 打包成 dist\AutoLoud.exe
python run.py --mock     # 任何系统：用软件模拟器跑界面（没有真实声卡也能开发）
python -m pytest -q      # 单元测试：LUFS 对拍、控制器闭环仿真
```

推到 GitHub 后，`.github/workflows/build.yml` 会在每次 push 时跑测试并在 Windows 上打包；打 `v*` 标签会自动发布 Release 并附上 exe。

## 工作原理（给开发者）

```
Windows 音频引擎 ──► 各应用会话混音 ──► WASAPI loopback 回录 ──► BS.1770 LUFS 实时测量
                          ▲                                                   │
                          │ ISimpleAudioVolume（每个应用的会话音量，≤ 0 dB）     │
                          └──────────────── 增益控制器 ◄───────────────────────┘
                                             │
                     IAudioEndpointVolume（主音量，只在需要“提升”时高于校准参考值）
```

- `autoloud/dsp/loudness.py` — 流式 BS.1770-4：K 加权、瞬时 / 短时 / 带门限的积分响度，与 pyloudnorm 对拍误差 < 0.2 LU。
- `autoloud/core/controller.py` — 纯逻辑的增益控制器（IDLE → ONSET → STEADY，三条规则），可离线仿真。
- `autoloud/core/engine.py` — 回录 → 测量 → 决策 → 下发音量；主音量可见性探测。
- `autoloud/backends/windows.py` — PyAudioWPatch（loopback）+ pycaw（音量）；所有 COM 调用集中在一个线程。
- `autoloud/backends/mock.py` — 同接口的软件模拟器。
- `autoloud/ui/` — PySide6 界面：总览、校准向导、应用混音、设置、托盘。

这条「监听 + 控制音量」路线不替换音频流，所以做不了逐采样的限幅 / 压缩；换来的是免驱动、零延迟，并且天然知道是哪个应用在发声。`Backend` 接口已为将来的虚拟声卡后端预留。

## 已知问题与路线图

- 蓝牙耳机的主音量在设备端生效，回录看不到；程序会在校准时自动探测并按「不可见」处理，但探测信号仍待改稳。
- 自动混音（通话优先、音乐让路）将建立在现有的每应用偏移之上。
- 按曲目 / 视频识别来源（Windows Media Session API），切歌时重置分析窗。

## 日志

`%APPDATA%\AutoLoud\` 下：`autoloud.log` 是运行日志；`adjust-<时间>.log` 是每次运行的音量决策记录，和首页活动卡片同样的措辞，每行附当时在发声的应用；`meters-<时间>.csv`（每 100 ms 一行：瞬时 / 短时 / 窗口积分 LUFS、采样峰值、总增益、应用衰减、主音量提升、状态、P、主音量）和 `apps-<时间>.csv`（每 0.5 s、每个发声应用一行：峰值表、会话音量、总线增益、推子，以及该应用独自发声时去掉全部增益后的源响度 `src_momentary_lufs` / `src_short_lufs`）是原始测量数据，供分析。这些文件都不会自动清理。

想看某个应用在一次运行里的历史曲线：`pip install pandas matplotlib` 后运行 `python tools\plot_app.py ZenlessZoneZero.exe`（默认最近一次运行，可跟运行时间戳指定），会在当前目录（项目目录）生成 `<应用>-<时间>.png`，三幅图共用时间轴：该应用的峰值表（dBFS）与会话音量；总线的瞬时 / 短时 / 窗口积分感知响度与 P，绿色底表示那段时间只有这个应用在发声（此时总线响度就是它的响度——程序只测整体混音的 LUFS，没有逐应用的 LUFS）；该应用自身的源响度（去掉总线增益、推子、会话音量之后，即它在 100 % 会话音量、参考主音量下的响度；只有它独自发声的时段才有）；总线增益、推子与会话音量。
